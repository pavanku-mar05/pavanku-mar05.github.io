PAVAN KUMAR — PREMIUM EMBEDDED SYSTEMS PORTFOLIO

FILES
- index.html: website content and page structure
- style.css: responsive visual design and animations
- script.js: navigation, scroll reveals, circuit roadmap, and interactive Three.js scene
- assets/pavan-portrait.jpeg: portrait supplied by Pavan
- resume.pdf: resume PDF supplied for this portfolio

RUN LOCALLY
1. Extract the ZIP while preserving its folder structure.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. Internet is required for Google Fonts and the Three.js CDN. The main design and portrait still work without those external services; the 3D chip falls back to a CSS illustration if Three.js cannot load.

PUBLISH (GITHUB PAGES)
1. Create/open the repository for your portfolio on GitHub.
2. Upload all files and folders from this directory (not the ZIP itself).
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the site.

EDITING
- Update text and links in index.html.
- Replace assets/pavan-portrait.jpeg with another photo using the same filename to change the portrait.
- Replace resume.pdf with your updated resume PDF.
- Colors and typography are defined at the top of style.css in :root.

ACCURACY NOTES
- Skills indicators are self-assessment visuals, not measured proficiency scores.
- Project progress bars represent portfolio roadmap/stage descriptions, not verified performance metrics.
- Please verify contact details and resume content before publishing publicly.
